# __App__

Generated by `rails new`. Every rule below is enforced by a test, a lint or a
deny; the file that enforces it is named.

## Commands

- `rails check` -- the lanes this diff selects (`lanes.toml`). `--quick` before an early push.
- `rails ship` -- one PR per line of work: opens it Ready, arms auto-squash, binds the monitor.
- `uv run pytest -q` -- backend; needs Postgres (`DATABASE_URL` is the admin DSN; tests create and drop `rails_planted_*` databases only).
- `pnpm --dir frontend run check` -- lint, typecheck, vitest.
- `uv run python scripts/walk.py` -- the planted walk. Step `a1` fails until Export CSV exists; that failure is honest.
- `uv run python scripts/gen.py all` -- regenerate; `--check` is the `gen` lane.

## Walls

- A setting is a row in `settings.toml`, read through `Settings` -> `test_settings_parity.py`.
- A wire shape is `contracts/wire.py`; never hand-edit `wire/` or `frontend/src/gen/` -> `test_contracts.py`.
- Events, schedules, screen states live in `contracts/registry.py` -> `test_identifier_registry.py`.
- Seams are wired only in `src/__app__/roots/`; a None seam refuses to boot -> `test_root_parity.py`.
- The wall clock is read only in `clock.py`; engines take `clock` without a default -> `test_clock_lint.py`.
- A bound is a `limits.py` name; a cap is race-free -> `test_limits_lint.py`, `test_caps_parallel.py`.
- A figure has a concept row, an owner and an oracle -> `test_concepts.py`, `test_surface_parity.py`.
- A route has an `auth_matrix.toml` row -> `test_auth_matrix.py`. Tables have RLS -> `test_rls_unbound.py`.
- Screens: no `?? []`, money only via `<Figure>`, every control has `data-control`, no raw `fetch` -> `frontend/eslint-rules/`.
- Planted values only. Real data never enters this repo.
- `X-Member` is a dev-only scheme behind `ALLOW_DEV_AUTH`; replace the `auth` seam before any real deploy.
